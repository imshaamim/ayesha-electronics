# আয়েশা ইলেকট্রনিক্স কিস্তি ম্যানেজার: cPanel-এ আপলোডের গাইড

সাইট চলবে: **https://ayesha.shaamim.com**
আপলোড ফাইল: `dist/ayesha-app-v0.0.2.zip`
সময় লাগবে: প্রায় ১০ মিনিট

---

## ধাপ ১: PHP ঠিক করুন (শুধু প্রথমবার)

1. cPanel → **Select PHP Version** (বা "MultiPHP Manager") খুলুন।
2. `ayesha.shaamim.com`-এর জন্য **PHP 8.1 বা নতুন** (8.2/8.3 হলে ভালো) বেছে নিন।
3. **Extensions** ট্যাবে নিচেরগুলোতে টিক আছে কিনা দেখুন, না থাকলে টিক দিন:
   - `pdo_sqlite` ✅ (জরুরি)
   - `sqlite3` ✅
   - `gd` ✅ (ছবি ছোট করার জন্য)
   - `zip` ✅ (ব্যাকআপের জন্য)
   - `fileinfo` ✅
   - `exif` (ঐচ্ছিক, মোবাইলের ছবি সোজা রাখতে)

## ধাপ ২: SSL চালু করুন (শুধু প্রথমবার, খুব জরুরি)

এখন সাবডোমেইনের SSL "Self-signed"। এতে পাসওয়ার্ড আর NID-এর তথ্য অরক্ষিত থাকে।

1. cPanel → **SSL/TLS Status**
2. `ayesha.shaamim.com` আর `www.ayesha.shaamim.com`-এ টিক দিন → **Run AutoSSL**
3. কয়েক মিনিট পর সবুজ তালা দেখা যাবে। না হলে HostSeba সাপোর্টকে বলুন: "Please enable AutoSSL for ayesha.shaamim.com"।

## ধাপ ৩: ফাইল আপলোড

1. cPanel → **File Manager**
2. ডান দিকে উপরে **Settings** → **Show Hidden Files (dotfiles)** টিক দিন → Save।
   (`.htaccess` নামের নিরাপত্তা ফাইলগুলো দেখার জন্য।)
3. বাঁ দিকের তালিকা থেকে **`ayesha.shaamim.com`** ফোল্ডারে ঢুকুন।
4. উপরে **Upload** → `ayesha-app-v0.0.2.zip` বেছে নিন → ১০০% হওয়া পর্যন্ত অপেক্ষা করুন।
5. File Manager-এ ফিরে zip ফাইলে Right-click → **Extract** → ফোল্ডার হিসেবে `/ayesha.shaamim.com` থাকবে → **Extract Files**।
6. Extract হয়ে গেলে zip ফাইলটি **Delete** করে দিন।

ফোল্ডারে এখন থাকবে: `index.php`, `.htaccess`, `assets/`, `src/`, `views/`, আর আগের `php.ini`।
⚠️ `php.ini` ফাইলটা মুছবেন না, ওটা হোস্টিংয়ের নিজের ফাইল।

## ধাপ ৪: প্রথমবার চালু করুন

1. ব্রাউজারে খুলুন: **https://ayesha.shaamim.com**
2. লগইন পেজ আসবে → পাসওয়ার্ড: **12345**
3. প্রথমবার খোলার সময় সফটওয়্যার নিজে থেকে এই ফোল্ডারটি তৈরি করবে:
   `/home/shaamimc/ayesha-data/` (এখানে থাকবে সব হিসাব আর ছবি)
4. **সেটিংস**-এ গিয়ে দোকানের ফোন নম্বর, মালিকের নাম ঠিক করে **সেভ** করুন।

## ধাপ ৫: নিরাপত্তা পরীক্ষা (২ মিনিট)

ব্রাউজারে এই লিংকগুলো খুলুন। প্রতিটায় **403 Forbidden** বা খালি পেজ আসা উচিত, কোড বা ডেটা দেখা গেলে চলবে না:

- https://ayesha.shaamim.com/src/db.php
- https://ayesha.shaamim.com/views/dashboard.php
- https://ayesha.shaamim.com/src/

আর লগআউট অবস্থায় https://ayesha.shaamim.com/index.php?r=customers খুললে লগইন পেজে চলে যাওয়া উচিত।

## ধাপ ৬: প্রথম ব্যাকআপ

**সেটিংস → সাপ্তাহিক ব্যাকআপ ডাউনলোড** চাপুন। ফাইলটি কম্পিউটার বা Google Drive-এ রাখুন।
এরপর প্রতি সপ্তাহে একবার। ৭ দিন পার হলে ড্যাশবোর্ডে হলুদ বার্তা মনে করিয়ে দেবে।

---

## পরে আপডেট করার নিয়ম

1. সফটওয়্যারে **সেটিংস → সাপ্তাহিক ব্যাকআপ ডাউনলোড** (সবসময় আগে)।
2. নতুন zip → File Manager → `ayesha.shaamim.com` ফোল্ডারে Upload → Extract (পুরনো ফাইলের উপর বসবে, "overwrite" জিজ্ঞেস করলে হ্যাঁ)।
3. zip মুছে দিন → সাইট খুলুন। ডেটাবেসে কিছু বদলাতে হলে নিজে থেকেই হবে।
4. সেটিংস পেজের নিচে **ভার্সন** নম্বর মিলিয়ে নিন।

⚠️ **`/home/shaamimc/ayesha-data` ফোল্ডারে কখনো হাত দেবেন না, মুছবেন না।**

## ব্যাকআপ থেকে ফেরত আনা (জরুরি অবস্থায়)

1. ব্যাকআপ zip খুলুন → ভেতরে `ayesha-data/data.db` আছে।
2. File Manager → `/home/shaamimc/ayesha-data/` → পুরনো `data.db` এর নাম বদলে `data-old.db` করুন।
   একই জায়গায় `data.db-wal` বা `data.db-shm` থাকলে সেগুলোর নামও বদলে দিন।
3. ব্যাকআপের `data.db` আপলোড করুন।
4. সাইট খুলে মিলিয়ে দেখুন। (ছবিগুলো `uploads` ফোল্ডারে আগের মতোই থাকবে।)

সার্ভারেও প্রতিদিন নিজে থেকে একটি কপি থাকে: `ayesha-data/backups/data-তারিখ.db` (শেষ ৩০ দিন)।
